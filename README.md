# POO_Java_TF_Gr2

Aplicación Java Swing para gestionar proyectos, clientes, gerentes y equipos, desarrollada según el diagrama del curso.

## Ejecutar

1. Abrir esta carpeta como proyecto en Apache NetBeans.
2. Seleccionar el proyecto y presionar F6.
3. La clase principal es `Vista.UsaProyecto`.

Se requiere un JDK. No necesita bibliotecas externas ni base de datos. El formulario `UsaProyecto.form` se puede editar en Design.

## Funciones

Registro y consulta de proyectos; clientes Empresa y PersonaNatural; gestión del equipo y estados; cálculo de fecha final; persistencia en `datosProyectos` y `datosClientes`.
